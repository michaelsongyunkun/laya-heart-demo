# Laya-Heart online demo

The real Laya-Heart page, running in your browser tab with stand-in models: its cards and replies
are placeholders, not model output, and a banner at the top says so. Nothing you type leaves the tab.

The app itself, with the real models running on your own computer, is at
https://github.com/sykyyds3739/laya-heart (MIT). This repository only holds the demo's static
build (`npm run build:demo`), deployed to Render as a static site by `render.yaml`.
